# Ooru – Social Networking Website

A simple social networking web app built with HTML, CSS and JavaScript (no frameworks).

## Features
- Create an account (name, username, bio)
- Post updates (280 chars) with #hashtags
- Like, comment and delete posts
- Follow / unfollow people
- Trending hashtags
- Profile page with followers/following count
- Light and dark mode, mobile friendly
- Data saved in the browser (localStorage)

## Run
Open `index.html` in any browser.

## Tech
HTML5 · CSS3 · Vanilla JavaScript
